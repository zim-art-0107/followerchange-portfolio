# FollowerChange

**A privacy-first follower tracking web application.**

[Visit FollowerChange](https://followerchange.com)

FollowerChange is a web application designed to help users understand their follower relationships and identify accounts that do not follow them back, with a focus on privacy.

## Features

- Follower relationship analysis
- Identification of accounts that do not follow back
- Privacy-focused product positioning
- Web-based user experience

## Tech Stack

- Next.js
- React
- TypeScript
- Web technologies

*Technology details should be verified against the actual source code before relying on this list.*

## Project Goals

- Build a practical web application for social media users.
- Make follower relationship information easier to understand.
- Prioritize user privacy and a clear user experience.
